# Changelog archive

Older changelog entries, rotated out of the live changelog.

The [current changelog](../CHANGELOG.md) is where entries start.
When a version's entries are no longer useful day to day, they move
here as a single file named for that version.

Archives are split by version rather than by date.
A version is the unit that means something to a reader looking back;
a month is not.
Entries within each file stay most-recent-first.

Archived files are kept only while they are worth keeping.
Compressing an old archive, or deleting one outright, is expected
rather than exceptional.
